# M5: interactive timeline picker (in progress)

M4.5 closed after [all three OS gates passed](https://github.com/Adiiitu12312/paradox/actions/runs/38739659259).
M5 implements `paradox timeline` with `inquire` and the existing loops view.

Candidates are the sorted union of native Git tracked status, newly explicit
tracked paths, and the native net diff from `HEAD~3` to the working tree. With
fewer ancestors, use the root commit; unborn repositories show only eligible
uncommitted paths. Raw untracked directories are never enumerated. Recently
deleted and renamed paths remain selectable. A change later reverted to its
boundary content is excluded unless currently dirty, matching the brief's diff
semantics. An explicitly listed path already committed and clean outside the
window is excluded.

The prompt retains exact root-relative paths internally and escapes control
characters for display. Selecting opens the shared loops view with fallback
capture and the HEAD baseline. No loop-store connection or lock exists while
waiting; opening is deferred until selection and uses fresh repository state.
Esc and Ctrl+C return success without creating a store. Empty candidates print
a clear message without requiring a terminal. Help parses outside a repository.

Core tests cover 0–5 commits, root/window boundaries, reused repository discovery,
net reverts, dirty/staged/deleted/renamed/conflicted paths, explicit tracking,
untracked noise, unusual filenames and `-C` subdirectory invocation. CLI tests
cover help, empty/unborn/clean repositories and nonterminal failure without
sidecar writes. Native PTY/ConPTY tests cover selection, filtering, cancellation,
Unicode paths, concurrent capture and absence of a lock while choosing.

Hosted formatting, linting, functional tests and native terminal acceptance are
pending. M5 is not complete until its required checks pass. All executable tests
use disposable OS-temp repositories. Frontend work begins at M6 locally using
the existing Node/npm; no Node downgrade or large Windows SDK installation.

The first hosted build compiled and passed Clippy; its command-availability
fixture was updated because `timeline` is now implemented. In the first complete
matrix, Linux and macOS functional and native picker tests passed. Windows
highlighted a backend behavior: the locked crossterm backend can open `CONIN$`
despite redirected stdin and wait indefinitely. The command now explicitly
requires terminal input and terminal stderr (the prompt's rendering stream)
before opening the prompt. Empty results and help still work noninteractively,
and selected loop output can still be redirected on stdout. The corrected
source requires a fresh all-OS acceptance run.
