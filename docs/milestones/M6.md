# M6: local browser workspace (in progress)

M1–M5 remain accepted. M6 is not complete until browser tests, all operating
systems, security checks and the existing performance gates pass.

Implemented draft: loopback-only authenticated server, session-cookie bootstrap,
tab-bound lifetime, embedded local assets, paginated virtual commit history,
commit details, working/index diff with Monaco, file/hunk/line staging and
unstaging, index-only commits and amend confirmation. Commit execution shares
the CLI's hooks, mandatory marker stripping and loop retention code.

The UI runs through `paradox ui`; `--no-open` prints its private session URL
without launching a browser. It never starts `paradox watch`. Closing the last
tab shuts down the server after a two-second reload grace. Ctrl+C also stops it.

Local frontend validation uses the owner's unchanged Node v26.4.0/npm11.17.0.
The build, TypeScript and ESLint checks pass; eight component/API tests pass.
Dependencies are installed only in `frontend/node_modules`; the npm audit after
the pinned DOMPurify override reported zero vulnerabilities. Rust is built on
GitHub, without a local C++ SDK or Rust compiler installation.

First hosted preparation run 38750675493 compiled the new implementation and
passed every Linux workspace functional test, including six native UI Git tests,
the 100,000-commit first-page bound, three asset tests and two authenticated-session
tests. Its strict Clippy step reported three style findings, subsequently fixed;
that run is not a complete M6 acceptance result. Subsequent validation remains
in progress.

## Local UI development

From the project directory, build with the existing Node installation:

```powershell
cd frontend
npm ci
npm run build
npm test
npm run lint
```

Use a hosted M6 binary in a disposable repository for testing. The hidden
development option `ui --assets-dir D:/plan/paradox/frontend/dist` serves the
local Node build through the authenticated Rust origin. Run `npm run build:watch`
in `frontend` for rebuilds, then reload the browser. No CORS exception or external
Monaco/font CDN is needed. A production binary embeds this same distribution.

Browser integration tests require `PARADOX_BIN` pointing to the compiled binary:

```powershell
$env:PARADOX_BIN = 'D:/path/to/paradox.exe'
cd frontend
npm run test:e2e
```

Windows tests use the already-installed Edge browser. Hosted CI installs its
browser runtime on GitHub's runner. Every executable test creates an OS-temp Git
repository; it never runs Paradox against the development checkout or user repos.
