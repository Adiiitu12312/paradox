## Local UI development

From the project directory, build with the existing Node installation:

```powershell
cd frontend
npm ci
npm run build
npm test
npm run lint
```

Use a hosted M6 binary in a disposable repository for testing. The hidden
development option `ui --assets-dir D:/plan/paradox/frontend/dist` serves the
local Node build through the authenticated Rust origin. Run `npm run build:watch`
in `frontend` for rebuilds, then reload the browser. No CORS exception or external
Monaco/font CDN is needed. A production binary embeds this same distribution.

Browser integration tests require `PARADOX_BIN` pointing to the compiled binary:

```powershell
$env:PARADOX_BIN = 'D:/path/to/paradox.exe'
cd frontend
npm run test:e2e
```

Windows tests use the already-installed Edge browser. Hosted CI installs its
browser runtime on GitHub's runner. Every executable test creates an OS-temp Git
repository; it never runs Paradox against the development checkout or user repos.
